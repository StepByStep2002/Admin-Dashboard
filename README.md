This is the "Admin Dashboard" project from the "Intermediate HTML & CSS" section of "The Odin Project" curriculum. The design was recreated according to the given example.

The purpose of this project is to practice newly learned skills learned in the said section, and especially to practice the usage of CSS Grid.
In this project I have used animal avatars from a website "Magnific": https://www.magnific.com/free-vector/flat-animal-heads-collection_839182.htm#fromView=detail&position=1&uuid=423a8b4c-f533-4087-9c56-80fca5a73880&track=ais_hybrid&from_element=cross_selling__vector
SVGs were picked from a website "Pictogrammers": https://pictogrammers.com/library/mdi/
